# Footage provenance

The bundled simulation is original programmatic illustration (`scene_design.py`), not real CCTV and not model-inferred boxes. Confidence is unavailable. Do not present screenshots from the uploaded design references as actual detections.

Supply a local MP4 you are authorized to film/process for actual model inference. No photographic sample with verified redistribution permission was supplied. Public-road reference downloads from previous iterations and derived outputs are excluded from this package.
